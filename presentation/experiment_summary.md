# Slide provenance

The 14-slide Beamer PDF uses the 2024 monthly walk-forward experiment in `output/crsp_monthly_walkforward_2024/`. There are five test folds (July–November), 105 daily test dates, and an untouched December lockbox.

| Slides | Content | Source |
| --- | --- | --- |
| 1 | Actual first and last date raw CRSP rows | `data/crsp_dsf_2024.csv.gz` |
| 2 | Effective-date filter stage counts | `data_audit.csv`, `run_metadata.json` |
| 3–5 | RET and SHROUT interpretation, eight features, executable label | `src/run_crsp_benchmark_2024.py`, `doc/pipeline.md`; WRDS CRSP data definitions |
| 6–9 | Objective, fold splits, fitted models, portfolio and 10 bps cost | `src/run_crsp_monthly_walkforward_2024.py`, `run_metadata.json` |
| 10 | MSE and daily mean IC | `model_comparison.csv`, `predictions.csv.gz` |
| 11 | Daily Rank IC points and 10-day rolling means | `ic_reversal.csv`, `ic_ridge.csv`, `ic_tree.csv` |
| 12 | Cumulative net returns on 63 common complete dates | `common_portfolio_dates.csv`, `portfolio_*.csv` |
| 13 | Net Sharpe, turnover, auxiliary classification and missing days | `model_comparison.csv`, `classification_metrics.csv` |
| 14 | Conclusions and next step | Same numerical outputs |

The separate `presentation/main (3).pdf` supplied by the user is the flattened annotated reference and is preserved. Slides 11–12 use high-contrast daily charts generated by `presentation/make_figures.py`. The portfolio comparison is conditional on complete selected-holding outcomes; no full 105-day P&L is claimed.
